# Depósitos — Smoke manual (dispositivo)

Checklist corta. No automatizar todavía.

1. **DEP-SAVE-001:** Nuevo depósito → seleccionar banco → Guardar y Enviar visibles/activos (sin cobros aún).
2. **DEP-SAVE-001:** Pulsar Guardar/Enviar sin cobros → modal de error; no abre confirmación.
3. **DEP-SAVE-001:** Pulsar Guardar/Enviar sin Nro. plantilla → modal indicando plantilla obligatoria.
4. **DEP-SAVE-001:** Seleccionar cobro(s) + completar plantilla → Guardar → confirmación → éxito → Guardar OFF.
5. **DEP-SAVE-002:** Tras guardar → Guardar OFF → editar comentario o cobro → Guardar ON → guardar de nuevo → OFF.
6. **DEP-SAVE-002:** Reabrir depósito guardado → Guardar OFF hasta primer cambio de usuario.
7. **DEP-SEND-001:** General OK → Enviar ON aunque falten cobros → pulsar Enviar → modal + hint en pestaña Cobros.
8. **Firma (`signatureCollection`):** sin adjuntos → modal al Guardar/Enviar.
9. **GPS (`userMustActivateGPS`):** sin coordenada → modal al Guardar/Enviar.
